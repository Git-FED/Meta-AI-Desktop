# GitHub build guide

This repository builds the Electron desktop app on GitHub Actions with a real Windows runner. The workflow does not require Wine or a local Windows machine in the GitHub environment.

## Windows app build

The workflow is [`../.github/workflows/build-windows.yml`](../.github/workflows/build-windows.yml). It runs on `windows-latest` and performs these steps:

1. Checks out the repository.
2. Installs Node.js 22 and runs `npm ci`.
3. Checks `main.js`, `preload.js`, and `renderer.js` syntax.
4. Runs `npm run build`.
5. Uploads the NSIS installer, portable executable, update metadata, and blockmap files as a workflow artifact.

The build configuration is [`../electron-builder.yml`](../electron-builder.yml). It points electron-builder at [`../assets/app-icon.ico`](../assets/app-icon.ico), which contains seven Windows icon layers.

## Triggering a build

- Push to `main` — builds and uploads artifacts.
- Open or update a pull request — builds and uploads artifacts.
- Use **Actions → Build Windows Electron app → Run workflow** — manual build.
- Push a tag beginning with `v`, such as `v300.0.0.0.153` — builds and creates a GitHub release with the Windows files.

A tag can be created locally with:

```bash
git tag v300.0.0.0.153
git push origin v300.0.0.0.153
```

The release job needs the repository's normal GitHub Actions `contents: write` permission. No signing certificate is included. For a production Windows release, configure code-signing secrets and add a signing step rather than committing a certificate or private key.

## Local Windows build

On Windows PowerShell:

```powershell
npm ci
npm run build
```

The output is written to `dist/` and includes:

- `Meta-AI-Desktop-<version>-x64.exe` — NSIS installer
- `Meta-AI-Desktop-<version>-portable.exe` — portable executable
- Update metadata and blockmap files generated by electron-builder

## Static site workflow

The optional [`../.github/workflows/deploy-pages.yml`](../.github/workflows/deploy-pages.yml) publishes only `site/` through GitHub Pages. It does not host the Electron application and does not create a Manus URL. GitHub repository Pages settings must be configured to use **GitHub Actions** before that workflow can publish.

The repository also includes [`../.github/workflows/validate.yml`](../.github/workflows/validate.yml), which checks JavaScript syntax, required Windows icons, the builder YAML file, and the static HTML routes.
